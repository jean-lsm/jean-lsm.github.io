The Mare Show
The first professional game launched

The game follows Tom Lorich, a compulsive gambler trapped in a bizarre world shaped by his deepest traumas. The Mare Show is a first-person horror and arcade game developed by OutZoom, released on October 21, 2025, for PC via Steam.

Project Overview

My Contribution

I worked as a programmer on The Mare Show, contributing to three main areas of the game's development:

  • HUD Programming: Implementation of user interfaces, real-time information updates, and integration with the game's systems.
  • Level Management: Programming for scene loading, transitions, progression, and game state management.
  • Localization Systems: Development and integration of the text localization structure, text identifiers, language switching, and interface localization. The game supports seven languages for its interface and subtitles.

This project provided professional experience contributing to a commercially released game developed by a team.

Public Showcases and Distribution

The Mare Show has been featured in public gaming showcases and distributed through digital platforms.

  • RetroCon 2025 — São Paulo, Brazil: The game was featured at the OutZoom / GoGo Games booth during this in-person gaming event.
  • Latin American Games Showcase (LAGS) 2025: The game was included in the showcase's selection of Latin American titles presented online.
  • Steam: Commercial release on October 21, 2025. A playable demo, The Mare Show: The Farm Demo, was previously released on May 9, 2025.
